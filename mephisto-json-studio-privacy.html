Core Privacy Guarantee (Chrome Web Store Limited Use):

This extension does not collect, transmit, store, sell, or rent any personal identification information (PII), browsing history, or user credentials to external servers. All operations execute strictly client-side within the local browser environment.

1. Single Purpose Specification

English: Format, validate, and convert JSON documents into TypeScript/Zod models and safely decode JWT tokens offline.

Türkçe: JSON verilerini tarayıcıda biçimlendirmek, TypeScript ve Zod şemalarına dönüştürmek ve JWT token'larını güvenle çözmek.

3. Permissions Justification & Usage

The extension requests only the minimum necessary Chrome APIs strictly required to provide its advertised functionality:

Permission API Technical Necessity & Single-Purpose Usage
storage Saves user settings, preferences, and local cache within chrome.storage.local. Never synced or uploaded to cloud endpoints.
activeTab / scripting Grants temporary, scoped access exclusively when the user clicks the extension action or keyboard shortcut to interact with the current tab.

4. BYOK (Bring Your Own Key) & Local Security

If the user optionally provides an external API key (such as OpenAI, Google Gemini, Anthropic Claude, or local Ollama), this key is stored strictly within the user's private browser sandbox (chrome.storage.local). The extension communicates directly and securely with the official vendor endpoints chosen by the user; no intermediary proxy or third-party server intercepts or accesses the credentials.
